## 회귀 범위

- 기준 도형의 형상·모멘트·위상 계산, 이미지 입력/오류 계약, Blob 그룹화.
- 윤곽 실패 전파, 8스레드 × 100회 공유 결과 읽기.
- 아키텍처별 pack1/4/8 및 두 헤더 순서의 ABI 컴파일 검사.
- x86 /Gd,/Gz,/Gr와 x64 /Gd,/Gv 소비자의 실제 DLL 호출.
- API 문서 예제: 2 Blob→1그룹, 조각2, 면적4, 중심(3.5,3), 평균200, 틈 픽셀 유지, source 해제 후 그룹 조회.
- 8개 패키지 ZIP을 별도 폴더에 추출하여 DLL 소비자와 API 예제 실행 성공.
- MFC 포함 6개 패키지는 실행 후 WaitForInputIdle 도달 확인. 화면 전체 기능의 자동 검증은 아니다.

총 84개 CTest 항목이 통과했다. ABI 컴파일 검사와 ZIP 실행 검사는 이 숫자에 별도로 포함되지 않는다.

## 검증에서 발견·수정한 문제

1. v141/v142 MFC 구성 요소 누락: runner에서 해당 컴포넌트를 명시적으로 설치했다.
2. SDK19041 리소스 컴파일러의 UTF-8 BOM 처리 오류(RC2135): 원본 UTF-8 BOM은 유지하고 빌드 폴더에 ASCII 리소스 입력을 생성했다. 비ASCII 리소스는 조용히 변환하지 않고 오류로 알린다.
3. PowerShell의 따옴표 없는 CMake 인수: Windows SDK 버전과 MFC 환경변수가 잘못 전달돼 SDK가 달라지거나 false가 적용되지 않았다. 인수를 따옴표로 감싸 실제 변수값을 전달한다.
4. v140 구성 요소에 멀티바이트 MFC 재배포 파일 부재: v140은 엔진 전용 패키지로 분리했다. v140 MFC 빌드 성공을 주장하지 않는다.

## 로컬 설치와 한계

로컬 VS2026의 v141/v142 MFC 설치는 처음 비상승 실행(5007), 다음에는 열린 Visual Studio 때문에(8006) 중단됐다. 사용자가 저장 후 IDE를 닫았으나 관리자 설치 재실행이 자동 승인 검토에서 차단됐다. 따라서 **로컬 MFC 추가 설치 완료를 주장하지 않는다**. 클라우드에서는 설치·빌드·실행을 완료했다.

로컬 v145는 리소스 수정 후 MFC 빌드와 CTest10/10 통과. 원본 BMP/정답 데이터 기반 정확도, HALCON 실물 대조, 깨끗한 PC 설치/제거, 장시간 P99 성능은 별도 미검증이다.

## 배포

0.0.2는 EXE8+ZIP8+SHA256목록8을 게시하는 prerelease다. 기존 0.0.1 자산은 교체하지 않는다. v140 설치파일에는 MFC 데모가 없고 v141/v142/v143에는 포함된다.
