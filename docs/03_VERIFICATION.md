# 03. 정의 검증 계획

> **구현보다 먼저 하는 일이다.**
> 정의(`docs/02_DEFINITIONS.md`)가 맞는지 틀린지를 코드 없이 먼저 판정한다.
> 정의가 틀린 채로 짠 코드는 전부 폐기 대상이므로, 이 문서가 게이트 역할을 한다.

## 1. 검증 3단계

| 단계 | 방법 | 산출물 | 필요 환경 |
|---|---|---|---|
| **V1. 손계산** | 해석적으로 값이 결정되는 기준 도형에 정의서 수식을 대입 | 기댓값 표 (§3) | 없음 |
| **V2. HALCON 실측** | HDevelop 에서 동일 도형을 만들어 오퍼레이터 실행 | 실측값 표 (§4) | HALCON 13 (HDevelop) |
| **V3. 구현 대조** | C++ 단위테스트 결과를 V1/V2 와 비교 | 테스트 리포트 | 구현 후 |

- **V1 과 V2 가 다르면 정의서가 틀린 것이다.** 정의서를 고치고 다시 V1 부터 한다.
- V2 를 못 하는 환경이면 V1 만으로 진행하되, **불일치 위험 항목을 명시**하고 넘어간다.
- V3 는 V1/V2 가 합의된 뒤에만 의미가 있다.

### 허용 오차

| 값의 성격 | 허용 오차 | 이유 |
|---|---|---|
| 정수 (Area, 픽셀 개수) | **완전 일치** | 오차가 있으면 정의가 다른 것이다 |
| 무게중심 (Row, Column) | `1e-9` | 유한합의 나눗셈, 부동소수 오차만 허용 |
| 윤곽 길이 (ContLength) | **완전 일치** (√2 항 포함 후 `1e-9`) | 체인코드는 이산 합이다 |
| 형상계수 (원/링 등 곡선 도형) | 이론값 대비 `±2%` | 이산화 오차가 본질적으로 존재 |
| 형상계수 (직선 도형) | `1e-9` | 이산화 오차 없음 |

## 2. 기준 도형 정의

모든 도형은 코드에서 재현 가능하도록 픽셀 단위로 못박는다.
좌표는 HALCON 관례 **(row, col)**, 좌상단이 (0, 0).

| ID | 이름 | 정의 | 목적 |
|---|---|---|---|
| **S1** | 정사각형 100×100 | `row ∈ [0,99]`, `col ∈ [0,99]` 전부 전경 | 모든 값의 기준. 해석해가 완전히 결정됨 |
| **S2** | 원판 R=50 | 중심 `(50,50)`, `(r-50)² + (c-50)² <= 50²` | 형상계수가 1 로 수렴하는지 |
| **S3** | 링(도넛) | 중심 `(50,50)`, `25² < (r-50)²+(c-50)² <= 50²` | **구멍 처리 검증** (contlength 함정 #4) |
| **S4** | 가로선 1×100 | `row = 50`, `col ∈ [0,99]` | 축퇴(degenerate) 예외 |
| **S5** | L자 | (좌팔) `row ∈ [0,99] × col ∈ [0,49]` ∪ (하팔) `row ∈ [50,99] × col ∈ [50,99]` | **convexity 검증** (오목 도형) |
| **S6** | 단일 픽셀 | `(50, 50)` 한 점 | 0 나눗셈 방어 |
| **S7** | 빈 리전 | 픽셀 없음 | 예외 반환값 |

### T-2. `contlength` ⚠ 최대 쟁점

정의서 미결 쟁점 **C-1**(윤곽 체인이 픽셀 중심 경로인가 픽셀 경계 둘레인가)을 판정한다.

**가설 A — 픽셀 중심 체인 (정의서 채택안)**
S1 정사각형의 경계 픽셀을 순회하면 `(0,0)→(0,99)→(99,99)→(99,0)→(0,0)`
= `99 + 99 + 99 + 99 = 396` 스텝, 전부 축평행.

**가설 B — 픽셀 경계 둘레**
`4 × 100 = 400`.

| 도형 | 가설 A | 가설 B | 판별력 |
|---|---|---|---|
| S1 정사각형 | **396.0** | 400.0 | ✅ 4 차이, 명확히 구분됨 |
| S4 가로선 | **198.0** | 202.0 | ✅ |
| S6 단일픽셀 | **0.0** | 4.0 | ✅ 가장 명확 |

> **판정 방법**: HALCON 에서 S6(단일 픽셀)의 `contlength` 를 찍는다.
> `0` 이면 가설 A, `4` 면 가설 B 다. **한 번의 실측으로 확정된다.**

**S3 링 — 구멍 처리 검증 (함정 #4)**

원문 Attention: *"The contour of holes is not calculated."*

| 해석 | 기댓값 | 계산 |
|---|---|---|
| **외곽만 (원문)** | **≈ 314.2** | `2π·50 = 314.159` |
| 구멍 포함 (오구현) | ≈ 471.2 | `2π·50 + 2π·25 = 471.24` |

> 두 값이 **1.5배** 차이 난다. `RETR_EXTERNAL` 을 안 쓰면 즉시 드러난다.
> 허용 오차 ±2% (곡선 이산화) → 외곽만 해석의 합격 범위는 **307.9 ~ 320.4**.

### T-3. `circularity`

```
C = min(1, F / (max² · π))
```

**S1 정사각형**
```
중심   = (49.5, 49.5)
max    = 모서리 (0,0) 까지 = sqrt(49.5² + 49.5²) = 49.5·√2 = 70.003571
max²   = 4900.5
분모   = 4900.5 · π = 15395.3748
C      = 10000 / 15395.3748 = 0.6495452
```
| 도형 | 기댓값 | 근거 |
|---|---|---|
| **S1 정사각형** | **0.6495452** | 위 계산. 오차 `1e-9` (직선 도형) |
| **S2 원판** | **1.0** | `A/(R²π) ≈ 7854/7853.98 ≈ 1.0000` → `min` 으로 1.0 클리핑 |
| **S3 링** | **≈ 0.75** | `A = π(50²−25²) = 5890.5`, `max = 50` → `5890.5/7853.98 = 0.75` |
| **S4 가로선** | **0.0129909** | `max = 49.5`, `49.5²·π = 7697.69`, `100/7697.69` |
| **S6 단일픽셀** | **0.0** | `max = 0` → 0 나눗셈 → 0 반환 (방어 규약) |
| **S7 빈 리전** | **0.0** | |

> **S2 가 1.0 을 넘어 클리핑되는지**가 함정 #1(`min` 클리핑) 검증이다.
> 클리핑을 빼먹으면 이산화 때문에 `1.0000x` 가 나와 Assertion 을 위반한다.

### T-4. `compactness`

```
C = max(1, L² / (4·F·π))
```
**`contlength` 결과에 연쇄 의존**하므로 T-2 확정 후 계산한다.

**S1 정사각형** (가설 A, L = 396)
```
L²     = 156816
분모    = 4 · 10000 · π = 125663.706
C'     = 156816 / 125663.706 = 1.2479019
C      = max(1, 1.2479019) = 1.2479019
```

| 도형 | 기댓값 (가설 A) | 참고: 가설 B 였다면 |
|---|---|---|
| **S1 정사각형** | **1.2479019** (L=396) | 1.2732395 (L=400) |
| **S2 원판** | **1.0** | — |
| **S4 가로선** | **31.1966** (L=198: `39204/1256.637`) | 32.4747 (L=202) |
| **S6 단일픽셀** | **1.0** 또는 0 ⚠ | — |
| **S7 빈 리전** | **0.0** | Assertion 이 `>=1.0 \|\| ==0` 이므로 0 |

> **S2 원판이 정확히 1.0 인지**가 함정 #2(`max` 클리핑, 방향 반대) 검증이다.
> `min` 을 쓰면 S1 에서 1.0 이 나와 즉시 드러난다.
>
> ⚠ **S6 미결**: 단일 픽셀은 `L=0, F=1` → `C'=0` → `max(1,0)=1.0`.
> 하지만 빈 리전 규약은 0 이다. HALCON 실측 필요.

### T-5. `convexity` ⚠ 최대 쟁점 (CV-1)

```
C = F_o / F_c
```
정의서 미결 쟁점 **CV-1**(`F_c` 가 폴리곤 면적인가 픽셀 개수인가)을 판정한다.

**S1 정사각형이 결정적 시험이다.**

| 해석 | `F_c` | `C = 10000 / F_c` | Assertion `<= 1` |
|---|---|---|---|
| **픽셀 개수** (정의서 잠정 채택) | 10000 | **1.0000** | ✅ 통과 |
| 폴리곤 면적 (`cv::contourArea`, 픽셀 중심 기준) | 99×99 = 9801 | 1.0203 | ❌ **위반** |

> **판정**: S1 에서 `1.0` 이 나오면 픽셀 개수, `1.02` 가 나오면 폴리곤 면적이다.
> HALCON 은 Assertion 이 `Convexity <= 1` 이므로 **픽셀 개수가 거의 확실**하지만, 실측으로 확정한다.
> 실무적으로도 `cv::contourArea` 를 쓰면 볼록 도형에서 1을 넘어 **모든 형상계수 스코어가 오염**된다.

| 도형 | 기댓값 (픽셀 개수 해석) | 근거 |
|---|---|---|
| **S1 정사각형** | **1.0** | 볼록 도형 |
| **S2 원판** | **≈ 1.0** (0.98 ~ 1.0) | 볼록이나 이산화로 hull 이 약간 큼 |
| **S3 링** | **≈ 0.75** | `5890.5 / 7853.98` — hull 은 꽉 찬 원판 |
| **S4 가로선** | **1.0** | 축퇴 hull = 자기 자신 |
| **S5 L자** | **≈ 0.87** | 아래 계산 ↓ |
| **S6 단일픽셀** | **1.0** | |
| **S7 빈 리전** | **0.0** | `F_c = 0` → 0 나눗셈 방어 |

**S5 L자의 hull 면적 (손계산)**
hull 꼭짓점 (row, col): `(0,0) (0,49) (50,99) (99,99) (99,0)`
픽셀 중심 기준 신발끈 공식 → **8551**
```
C(폴리곤) = 7500 / 8551 = 0.87709
```
픽셀 개수 해석이면 hull 래스터화 픽셀이 폴리곤보다 다소 많아 **8600 내외** → `C ≈ 0.872`.

> ⚠ S5 는 두 해석의 차이가 0.005 수준이라 **판별력이 낮다.** CV-1 판정은 **S1 로 한다.**

## 5. 결정적 판정 요약 (이 3개가 5종 구현의 전부를 좌우한다)

| # | 판정 항목 | 시험 도형 | 판정 기준 | 상태 |
|---|---|---|---|---|
| **P-1** | `contlength` 체인 정의 (C-1) | S6 단일픽셀 | `0` → 픽셀중심체인 / `4` → 경계둘레 | ⬜ 미확정 |
| **P-2** | `convexity` 의 `F_c` 단위 (CV-1) | S1 정사각형 | `1.0` → 픽셀개수 / `1.02` → 폴리곤면적 | ⬜ 미확정 |
| **P-3** | `contlength` 구멍 제외 (함정 #4) | S3 링 | `≈314` → 외곽만 / `≈471` → 구멍포함 | ⬜ 원문상 314 (Attention 명시) |

- **P-1 이 확정되면** `contlength` 와 `compactness` 가 동시에 확정된다.
- **P-2 가 확정되면** `convexity` 가 확정된다.
- **P-3 은 원문에 Attention 으로 명시**되어 있어 실측 없이도 외곽만으로 확정할 수 있다.
- `area_center` 와 `circularity` 는 쟁점이 없어 **손계산만으로 검증 완료 가능**하다.
