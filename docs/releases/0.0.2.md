# GlimHalcon SDK 0.0.2 (prerelease)

- v140/v141/v142/v143 × x64/x86 DLL 및 MFC 데모 패키지.
- 툴셋별 컴파일러/MFC 구성 요소 설치 자동화.
- 각 조합의 전체 회귀검증, 추출 ZIP의 DLL 소비자 실행 및 MFC 시작 검사를 통과해야 배포한다.
- 함수 14개의 공식 API Reference, 툴셋 가이드 및 실행 가능한 그룹 예제 동봉.
- 기존 API v1 구조체/알고리즘 계약 유지. 소비자 아키텍처와 툴셋에 맞는 EXE/ZIP을 선택한다.

파일명 예: GlimHalconSDK-0.0.2-x64-v140.exe. 각 조합의 SHA256SUMS 파일로 다운로드를 확인한다.

자동 검증은 개발 도구가 설치된 Windows runner에서 수행한다. 깨끗한 PC의 설치/제거, HALCON 실측 일치, 현장 검출 정확도와 장시간 성능을 보증하지 않는다.
