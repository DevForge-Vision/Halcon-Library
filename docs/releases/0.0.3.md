# GlimHalcon SDK 0.0.3 (prerelease)

- Blob 및 그룹의 region_features 1~20 조회 API 추가. 기존 POD ABI 유지.
- MFC 결과 열에 20개 값, 한글 의미, 단위 표시. 오른쪽 가로 스크롤로 확인.
- dist_mean/deviation, inner_height/width/radius는 잠정 정의. HALCON 실측 동등성 미검증.
- v140~v143 x86/x64 패키지. v140은 엔진 전용, MFC는 v141~v143.
- 모든 조합의 회귀, ZIP 소비자/MFC 시작, 설치/제거 검증 통과 후 게시.
- 로컬 v142/x64 회귀 11/11 통과. 상세 UI 실측 및 clean PC 검증은 별도.

사용법: docs/15_REGION_FEATURES20.md. 실패 결과를 실제 0값으로 사용하지 마세요.
