# GlimHalcon SDK 0.0.1
초기 시험 배포(Pre-release). 생산 적용 승인 버전이 아닙니다.

## 다운로드와 설치
- 64비트 MFC 프로그램: GlimHalconSDK-0.0.1-x64-v143.exe
- 32비트 MFC 프로그램: GlimHalconSDK-0.0.1-x86-v143.exe
- 설치 마법사에서 설치 폴더를 선택합니다. 관리자 권한이 필요할 수 있습니다.
- 설치하지 않고 사용하려면 같은 이름의 ZIP을 압축 해제합니다.
- SHA256SUMS-x64.txt / SHA256SUMS-Win32.txt로 파일 무결성을 확인할 수 있습니다.
- Windows/Visual Studio 2022 v143 Release용입니다. VS2015 v140 패키지는 포함하지 않습니다.
- include 헤더와 lib의 import library를 연결하고 bin의 GlimHalcon.dll 및 함께 제공된 runtime DLL들을 실행 프로그램 폴더에 배치하세요. SDK 설치만으로 MFC 프로젝트의 include/lib 경로가 자동 설정되지는 않습니다.
- 코드 서명 인증서는 아직 적용하지 않았습니다.

## 포함 기능
BMP/메모리 이미지 입력, Blob별 형상·모멘트·위상·밝기 feature, 끊어진 조각의 그룹화와 그룹 feature 반환.
DLL, import library, 공개 헤더, C++ 예제, MFC 데모, 문서와 Release CRT/MFC runtime 파일을 제공합니다. bin의 GlimMfcDemo.exe로 BMP를 열고 Blob/그룹 수치를 확인할 수 있습니다.

## 알려진 한계
- DLL packing의 include 순서 의존 및 윤곽 추적 비정상 종료의 실패 전파 문제(R1/R2)가 소스에서 수정되었습니다. 로컬 VS2026/v145 x64 9개·x86 10개 테스트와 DLL 소비자 검증은 통과했습니다. v143은 해당 Actions 실행 결과를 확인하세요.
- 실제 이미지 성능·오병합률, HALCON 실물 수치 일치, 깨끗한 PC 설치/제거 검증은 완료되지 않았습니다.
- workflow의 빌드/회귀 테스트 성공은 위 검증을 대체하지 않습니다.
- 16-bit/압축 BMP/JPG는 현재 파일 API에서 지원하지 않습니다.
- 자세한 점검: docs/06_STAGE1_SOURCE_REVIEW.md.

이 문서는 배포 준비 소스입니다. 실제 다운로드 자산은 Actions가 성공한 뒤에만 생성됩니다.
